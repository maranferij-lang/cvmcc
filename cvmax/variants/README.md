# Варіанти системного промпту

Тут лежать варіанти промпту, між якими бандит (Thompson sampling, `cvmax/learning/bandit.py`)
обирає для кожного нового розбору. Варіант не замінює промпт: його `text` дописується в самий
кінець системного промпту розбору (`analysis_system`), після рубрики. Порожній `text` означає
базовий промпт без змін.

Схема `analysis.json`:

    {"task": "analysis",
     "variants": [{"id": "v1-baseline", "active": true, "text": ""}, ...]}

- `id`: стабільний ідентифікатор. Статистика (лайки, прийняті правки, outcome) зберігається за id,
  тому id не можна перейменовувати чи використовувати повторно: новий текст означає новий id.
- `active`: чи бере бандит цей варіант у вибір. Бандит може сам вимкнути варіант-невдаху (`false`).
- `text`: інструкції англійською, які змінюють спосіб міркування, а не схему відповіді. Вони не
  можуть скасувати жорсткі правила базового промпту (нічого не вигадувати, плейсхолдери в дужках, без косметичних правок, `before` дослівно з CV).

Тижневий скрипт `scripts/learn.py` може дописувати нові варіанти з id `auto-<дата>`; видаляти варіанти не треба,
вимкнений варіант зберігає свою історію.
