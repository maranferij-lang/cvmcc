# Program rubric: Artificial Intelligence (KSE)

Typical targets: ML engineer intern, data scientist, AI/LLM engineer, research intern, data analyst.

Signals employers look for:
- Projects with a clear task, data, model, metric and result ("fine-tuned X on Y, F1 0.62 -> 0.78").
- Python ecosystem: PyTorch or TensorFlow, scikit-learn, pandas, NumPy; SQL for data roles.
- Applied LLM work: building with model APIs, retrieval, evaluation, agents, with a deployed demo.
- Research: papers, preprints, Kaggle rankings, reproductions of papers, RA work.
- Engineering around ML: data pipelines, experiment tracking, deployment, Docker.

Typical mistakes:
- Listing model names without what was achieved.
- Only course notebooks, no end-to-end project.
- Missing GitHub/Kaggle/Hugging Face links.
