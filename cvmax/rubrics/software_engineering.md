# Program rubric: Software Engineering (KSE)

Typical targets: backend, frontend, full-stack, mobile, QA automation, DevOps intern/junior.

Signals employers look for:
- GitHub or portfolio link with at least 2-3 real projects with READMEs.
- Projects described by what they do, the stack, and scale or result (users, requests, latency,
  test coverage, deployed link).
- Stack that matches the vacancy, with depth over breadth. Group skills: Languages, Frameworks,
  Databases, Tools/Cloud.
- Engineering practices: tests, CI/CD, code review, Git workflow, Docker.
- Hackathons, open-source contributions, competitive programming results.

Typical mistakes:
- Twenty technologies listed, none demonstrated.
- Projects described as "a website" without stack, features or link.
- University labs listed as projects without anything that stands out.
