# CVMAX

AI-помічник, який покращує CV студентів під конкретну роль. Пілот для студентів КШЕ, безплатно.

## Що вміє

1. **Онбординг.** Програма в КШЕ, курс, досвід, цільова роль, тип компанії, рівень, ринок і текст вакансії.
   Застосунок показує, наскільки чітко описана ціль. Бізнес-аналітик у консалтингу і у фінтеху мають різні
   вимоги, тому без типу компанії чи вакансії поради будуть загальніші.
2. **Аналіз CV.** PDF або DOCX. Оцінка 0-100, оцінки за 7 критеріями, сильні сторони.
3. **Правки «було / стало».** Кожну правку приймаєш або ні. Модель нічого не вигадує: де потрібне число,
   ставить `[X]` і каже, що туди вписати.
4. **Що вивчити.** Конкретні навички, сертифікати, проєкти під ціль, з оцінкою часу.
5. **Grill me.** До 8 питань по одному про досвід, який CV недооцінює. Відповіді перетворюються на нові правки.
6. **Готове CV.** Прийняті правки застосовуються до тексту, завантаження в DOCX, TXT і список правок у Markdown.

## Як запустити локально

Потрібен Python 3.10+.

```bash
git clone https://github.com/maranferij-lang/cvmcc.git
cd cvmcc
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .streamlit/secrets.toml.example .streamlit/secrets.toml
# встав свій ключ у .streamlit/secrets.toml
streamlit run app.py
```

Без ключа застосунок відкривається в демо-режимі із заготовленими відповідями.
Так можна подивитись інтерфейс, не витрачаючи кредити.

Ключ API створюється на [platform.claude.com](https://platform.claude.com) у розділі API keys.
Кредити на API і підписка Claude Pro/Max це різні речі: для CVMAX потрібні саме кредити API.

## Як викласти для студентів

Найпростіше через [Streamlit Community Cloud](https://streamlit.io/cloud), це безплатно.

1. Репозиторій на GitHub, де лежить `app.py`.
2. На streamlit.io: New app, обрати репозиторій і файл `app.py`.
3. В Advanced settings, Secrets, вставити `ANTHROPIC_API_KEY = "sk-ant-..."`.
4. Отримати посилання і кинути студентам.

Постав місячний ліміт витрат на platform.claude.com, щоб публічне посилання не з'їло всі кредити.

## Налаштування

Усе через змінні середовища або Streamlit secrets.

| Змінна | За замовчуванням | Що робить |
|---|---|---|
| `CVMAX_MODEL` | `claude-opus-5-5` | Модель. `claude-sonnet-5-5` удвічі дешевша |
| `CVMAX_EFFORT_ANALYSIS` | `high` | Глибина аналізу: low, medium, high, xhigh, max |
| `CVMAX_EFFORT_GRILL` | `low` | Глибина для питань Grill me |
| `CVMAX_FALLBACKS` | `1` | Повтор на запасній моделі, якщо основна відмовить |
| `CVMAX_DEMO` | вимк. | `1` вмикає демо-режим навіть із ключем |

## Як це влаштовано

Модель не тренується. Уся якість іде з контексту, який вона отримує в кожному запиті:
CV, профіль юзера, ціль, текст вакансії і рубрика.

```
app.py                 інтерфейс (Streamlit)
cvmax/profile.py       дані онбордингу, чіткість цілі
cvmax/cv_input.py      читання PDF і DOCX
cvmax/prompts.py       системні промпти
cvmax/rubrics/*.md     критерії: загальні + окремо для кожної програми КШЕ
cvmax/analyze.py       повний аналіз
cvmax/grill.py         режим Grill me
cvmax/edits.py         застосування правок і експорт
cvmax/schemas.py       формат відповідей моделі
cvmax/llm.py           виклик Claude API
cvmax/demo.py          фейковий клієнт для демо і тестів
```

Відповіді моделі приходять як структурований JSON за схемою з `schemas.py`, тому інтерфейс не ламається
від несподіваного формату. PDF надсилається моделі як документ, щоб вона бачила ще й верстку.

**Покращувати якість найпростіше через рубрики.** Це звичайні текстові файли в `cvmax/rubrics/`.
Додай туди, що реально шукають рекрутери у твоїй сфері, і поради стануть точнішими без жодного коду.

## Приватність

CV надсилається в Claude API тільки для аналізу. CVMAX нічого не зберігає: дані живуть у сесії браузера
і зникають, коли вкладку закрито. Перед завантаженням юзер дає згоду на обробку.
